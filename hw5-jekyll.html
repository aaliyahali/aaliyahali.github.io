--- ## Chart 1: Top 20 Illinois Professional License Types
**What is being visualized:** This horizontal bar chart displays the 20 most common professional license types issued in Illinois, ranked from most to least frequent. Each bar represents one license category (e.g., Registered Nurse, Real Estate Broker), and the bar length encodes the total count of licenses held in that category. This gives a quick overview of which professions are most heavily licensed in the state. **Design choices – encodings:** The x-axis uses a quantitative encoding to represent the count of licenses, while the y-axis uses a nominal encoding for license type, sorted in descending order by count so the most common types appear at the top. This combination of a quantitative and nominal axis in a horizontal bar chart is well-suited for comparing labeled categories where the label text can be long. **Design choices – colormap:** Bars are colored using the `tealblues` sequential color scheme, mapped to the count value. This scheme progresses from light to dark teal, reinforcing the magnitude already encoded in bar length — darker bars are more common license types. A sequential scheme is appropriate here because count is a continuous quantity with a natural ordering from low to high. When a bar is not selected via interactivity, it dims to light gray, making the selected bar visually prominent. **Data transformations:** In the Python notebook, I used `value_counts()` on the `License Type` column to aggregate raw license rows into per-type totals, then sliced the result to the top 20 entries. No date parsing or filtering by other columns was needed for this aggregation — the transformation was purely a groupby-and-count. **Interactivity:** This chart uses a point selection (`selection_point`) so that clicking any bar highlights it in the teal color scheme while all other bars dim to gray. This interaction helps users focus on a specific license type — particularly useful when comparing a particular bar against others in a dense ranking. Tooltip information (exact count, formatted with commas) also appears on hover, giving precise values without cluttering the chart with data labels. --- ## Chart 2: License Status Breakdown for Top 10 License Types
**What is being visualized:** This normalized stacked bar chart shows the proportional breakdown of license statuses — such as Active, Expired, or Inactive — across the top 10 most common professional license types in Illinois. Rather than showing raw counts, each bar is scaled to 100% so the viewer can directly compare the composition of statuses across very different-sized professions. For example, it reveals whether certain license types have a higher proportion of expired licenses relative to others. **Design choices – encodings:** The y-axis uses a nominal encoding for license type (sorted by total count descending), and the x-axis uses a quantitative encoding displayed as a normalized percentage. Color encodes the license status category using a nominal mapping. The `stack='normalize'` option in Altair transforms the bars so all extend to 100%, shifting the focus from total volume to proportional composition — which is the analytical question this chart is designed to answer. **Design choices – colormap:** The `tableau10` categorical color scheme is used to distinguish license statuses. Since status is a nominal variable with no inherent ordering (Active is not "more than" Expired in a numeric sense), a qualitative/categorical scheme is the correct choice. `tableau10` provides up to 10 visually distinct, perceptually balanced colors. Only the top 5 statuses by total count are retained to prevent the legend from becoming overcrowded with rare categories. **Data transformations:** In the notebook, I first filtered the dataframe to only rows whose `License Type` is in the top 10 list derived from Plot 1. I then used `groupby(['License Type', 'License Status']).size()` to count combinations, and further filtered to keep only the 5 most common status values (summed across all license types). This two-step filtering was necessary to keep the chart readable — the raw data contains many rare status strings that would fragment the stacked bars into thin, illegible slivers. **Interactivity (Plot 1 discussion continued):** The interactivity in Plot 1 — click-to-highlight — directly improves clarity by allowing the viewer to isolate one license type from a crowded ranking of 20. In a static chart, it can be hard to compare a bar in the middle of the list against one at the top. With click selection, the user can highlight each bar in sequence and read the tooltip for an exact count, making the chart serve both an overview role and a detail-on-demand role within a single view. The tooltip on Plot 2 further supports detail-on-demand: hovering reveals the raw count behind each proportional segment, so the normalized view does not hide absolute magnitudes.
